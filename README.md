# ジェネラティブ万華鏡

画面をなぞるだけで、万華鏡のような模様が描けるお絵かきアプリです。

描いた線は、画面の中心を軸に回転してコピーされます。
なぞる速さによって、線の色・明るさ・太さが変わります。

## 使い方

`index.html` をブラウザで開くだけで動きます。
インストールやビルドは不要です。

マウスでドラッグするか、指やペンで画面をなぞって描きます。

## 操作パネル

| 項目 | 内容 |
|---|---|
| 対称 | 模様を何方向にコピーするか（2〜24、初期値 8） |
| 太さ | 線の基本の太さ（1〜20、初期値 4） |
| 鏡像 | オンにすると、左右反転した線も描く |
| 発光 | オンにすると、線がぼんやり光る |
| ↶ 戻す | 1つ前の状態に戻す（最大 25 回） |
| クリア | 画面をすべて消す |
| PNG保存 | 描いた絵を PNG 画像として保存する |

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Z` / `Ctrl+Z` | 元に戻す |
| `C` | クリア |
| `S` | PNG で保存 |

## 補足

- ウィンドウの大きさを変えると、「戻す」の履歴はリセットされます。
- 保存したファイル名は `kaleidoscope-日時.png` になります。
